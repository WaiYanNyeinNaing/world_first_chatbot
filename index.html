ELIZA showed that simple rules can feel strangely human.

Built by Joseph Weizenbaum in 1966, ELIZA matched user input against hand-written patterns and responded with scripted reflections. Its famous Rogerian therapist simulation asked people to keep talking, which made the program feel much more intelligent than its mechanics really were.

What ELIZA actually does

  • Matches input with simple keyword and pattern rules
  • Reflects pronouns to keep the reply conversational
  • Falls back to open-ended prompts when no rule fits
How it works

Rule-based pattern matching

ELIZA does not understand language in the modern AI sense. It uses deterministic pattern matching, decomposition templates, and reflection rules to turn a sentence back into a therapeutic question.

Keyword rules + pronoun reflection + fallback prompts
Why it matters

An ancestor of conversational AI

ELIZA is often described as an ancestor, and sometimes a godfather, of ChatGPT-era conversational systems because it showed how powerful the illusion of understanding can be when a system mirrors the user well.
